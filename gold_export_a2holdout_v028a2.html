このページがしないこと
  • localStorage へ1バイトも書きません（getItem と length しか触りません）。
  • キーの列挙（localStorage.key() / Object.keys(localStorage)）をしません。
  • A2 holdout 2本（sms5xyl4jjy / smrg85jwsn6）以外のキーを1度も読みません。 開発4本も、E4 holdout 2本も、他の物語も、削除済みも開きません。
  • 同期の値（baseRev / sharedRev / dirtyTs / pushedTs / fork）を読みません。
  • APIキー・合言葉・ログイン情報を読みません。
  • 外部リソースを1つも読み込みません（index.html / features.js / 本番パッチ群を含む）。
  • fetch / XHR / sendBeacon / WebSocket / EventSource を呼びません。Service Worker を登録しません。
  • eval / new Function を使いません。IndexedDB を開きません。
  • 画面へ innerHTML で文字列を差し込みません（表示は全部 textContent）。
  • 自動ダウンロードしません。Blob はクリック後・全条件合格後にしか作りません。
  • 条件を1つでも外したら部分書き出しをせず停止します（fail-closed）。
前提：Chronicle と同じオリジンで、このページの URL を直接開いてください （file:// は不可。物語画面・ホーム画面を経由しないでください）。

v0.2.8 の修正（GPT再監査 2026-08-04 反映）
  • ①→② の間の chr6_slots_meta 変更を再検証する（TOCTOU の封鎖）。 ②の先頭で meta を読み直し、対象 slot の存在・重複なし・deleted でないことを確かめ、 sourceMetaKey / sourceMetaKeyMatched / sourceMetaKeyMissing / sourceMeta / metaRaw / sourceMetaRawBytes / sourceMetaRawSha256 を②時点の meta から作り直す。 その検証を通ってから本体・roster・evid を読む。1つでも外れたら本体を読まず Blob も作らず停止する
v0.2.7 で入れた修正
  • byte長を UTF-8 で数える。String.length（UTF-16 コードユニット数）ではなく new TextEncoder().encode(s).byteLength。対象は bodyBytes / rosterBytes / evidBytes / sourceMetaRawBytes
  • cast をホワイトリスト化。hero と npcs[] をそれぞれ id と name だけに絞る。元の cast 全体は出力しない
  • sourceMeta をホワイトリスト化。id / name / key / deleted だけ。元 meta 全体の同一性は sourceMetaRawSha256 と sourceMetaRawBytes で担保し、生 meta は出力しない
  • meta.key 不一致は本体を読まず fail-closed。 expectedBodyKey / sourceMetaKey / sourceMetaKeyMatched / sourceMetaKeyMissing を成果物へ記録。欠落（null）は記録して続行、不一致は拒否

手順

2. このページの URL をアドレスバーへ直接入力して開きます（物語画面・ホーム画面を経由しない）。
3. 「① 読む」を押します。holdout 2本は最初から選択済みです。
4. 「② 書き出す」を1回だけ押すと dev156_raw_holdout_YYYYMMDD.json がダウンロードされます。
5. 画面下の「記録用テキスト」をコピーして保存し、JSON を会話へ添付してください。
