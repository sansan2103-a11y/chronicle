## 表の見方（「既定」の欄）

| 書き方 | 意味 |
|---|---|
| 全員 ON | 本番で、だれが開いても最初から動いている |
| Owner 限定 | 本番にあるが、Owner のアカウント（サーバーが Owner と判定したとき）だけで動く |
| 端末で ON | 本番にあるが最初は止まっている。その端末で設定（スイッチ）を入れたときだけ動く |
| アカウントごと | 本番にあるが、管理者画面でそのアカウントを ON にしたときだけ動く（80-int-a から） |
| 候補 | 手元（Local）で作って試験した段階。**まだ本番には入っていない** |
| 止めている | 本番に部品はあるが、今は使わない設定になっている |
| 未確認 | 本番にあるが、既定でどうなっているかをまだ確かめていない |

「止めるスイッチ」は、急いで止めたいときに開発担当がその端末だけで使うものです（Owner が覚える必要はありません）。

## 8. 見えないところで動いている安全装置（Owner の操作は不要）

- **保存の安全装置**：保存の失敗を黙らせない、複数タブでの上書き、古い端末での巻き戻し、未保存の進行がクラウドの古い版で消える、を防ぐ。保存の直近 3 世代の控えも自動で取る。
- **削除の安全装置**：削除した物語が別の端末やクラウドから戻らないように「削除済み」の印を全体で守る。
- **隠した物語の安全装置**：隠した物語の中身を AI や外部に送らない・新しい複製を作らない。
- **画像の送信の安全装置**：キャラの名前や日本語の文がそのまま画像の AI に出ないように止める。
- **費用の安全装置**：アカウントごとの費用上限・全体の生成上限（管理者画面で設定）。
